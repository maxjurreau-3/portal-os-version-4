# Portal‑OS v4 Pipeline Integration

The Portal‑OS v4 pipeline mirrors the Cloudflare deployment flow.

## BUILD

Compiles the OS using Webpack.

## DEPLOY

Triggers Cloudflare Pages deployment.

## EXECUTE

Runs runtime checks inside the OS.

## VERSION

Tags the release for Umbrella ecosystem tracking.

The pipeline is accessible through the Shell UI under **Pipeline Viewer**.
