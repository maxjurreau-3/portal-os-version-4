# BEE System Icons — Portal‑OS v4

This folder contains the large-format BEE icons used across Portal‑OS v4:

- `icon-bee.svg` — primary bee symbol  
- `icon-bee-hex.svg` — hexagonal bee badge  
- `icon-bee-portal.svg` — bee inside the Portal ring  

These icons are designed for:

- Suite launchers  
- OS splash screens  
- Identity modules  
- Portal‑OS v4 branding  
- Umbrella ecosystem visuals  

All icons are high-resolution, vector-based, and Cloudflare‑safe.
